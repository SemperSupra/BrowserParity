# Edge0 resident-weight invariant diagnostic — temporary test instrumentation

Follow-on to public PR #25 confirmed 6/80 actual native unit-process failures across standard x64 and ARM64 public GHA. Hypothesis: an accounting mismatch in resident weight budget vs GGML backend allocation, not yet proven. This workcell compares the exact upstream test binary against a second binary that differs *only by two telemetry printouts*, after checking the test assertion source strings exactly. It never bypasses or weakens the source assertions. Each variant runs 80 fresh processes per runner and retains mismatch count, charged/allocated byte values and abbreviated public-safe failure excerpts as a machine-readable receipt. If failures persist, CI is red by design. If instrumentation suppresses failures, distinguish instrumentation effects from a fix. No real model checkpoint or private code, no paid runner or release.
